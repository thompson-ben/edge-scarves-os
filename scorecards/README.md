# Scorecards

Standardised, repeatable scorecards that turn judgement into numbers so progress is visible and comparable over time. Each scorecard is **copied and filled per review period** (don't overwrite the master) and produces a single headline score. They make "are we getting better?" answerable.

## How scoring works

- Each scorecard has weighted categories scored **1–10**.
- **Category score = rating × weight.** **Overall = Σ(category scores) ÷ Σ(weights) × 10**, giving a **0–100** result.
- Bands: **80–100 🟢 Strong · 60–79 🟡 Healthy · 40–59 🟠 Needs work · <40 🔴 At risk.**
- Always note the evidence behind each rating, and compare to the previous period's score.

> Verify the underlying data before scoring ([`docs/14-kpis.md`](../docs/14-kpis.md)). A scorecard built on bad data is worse than none.
