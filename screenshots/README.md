# Screenshots

Visual evidence for the business: audit findings, before/after CRO changes, bug reproductions, dashboard captures and competitor references. Screenshots make decisions and reviews concrete — "show, don't tell."

## What lives here
- Website audit evidence ([`docs/06-website-audit.md`](../docs/06-website-audit.md))
- Before/after for CRO changes and releases
- Bug reproductions ([`templates/bug-report.md`](../templates/bug-report.md))
- KPI / dashboard snapshots ([`docs/14-kpis.md`](../docs/14-kpis.md))

## Conventions
- **Naming:** `YYYY-MM-DD_<area>_<short-description>.png` (e.g. `2026-07-01_pdp_mobile-cta-above-fold.png`).
- Capture **mobile and desktop** where relevant (mobile is the majority).
- For before/after, keep both and label clearly.
- Suggested subfolders as volume grows: `audit/`, `before-after/`, `bugs/`, `dashboards/`.

> Store screenshots are evidence, not authorisation to change the store.
