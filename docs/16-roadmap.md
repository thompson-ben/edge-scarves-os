# 16 — Roadmap

## Purpose

The phased plan that connects today's foundation work to the £2,000/month and then £10,000+/month net-profit targets. The roadmap sequences effort so each phase builds on a proven previous one — convert before you scale traffic; retain before you spend more to acquire. It is directional, not a commitment of dates, and is revisited each sprint.

## Current State

**We are in Phase 0 — Foundation.**

### Phase 0 — Foundation (now)
- **Goal:** Build the operating system (this repository): docs, standards, AI team, sprint process.
- **Exit criteria:** Repository complete; baselines and access identified; Sprint 1 ready to start.
- **Status:** 🟢 In progress (Sprint 0).

### Phase 1 — Conversion (→ £2,000/month net)
- **Goal:** Establish baselines, audit the store, fix top conversion leaks, raise CR and AOV.
- **Why first:** Cheapest profit — improves return on traffic we already pay for.
- **Key work:** website audit → CRO backlog → first tests. See [`backlog/sprint-01-conversion.md`](../backlog/sprint-01-conversion.md).
- **Exit criteria:** Verified path to £2,000/month net, with conversion improvements proven.

### Phase 2 — Acquisition (profitable scale)
- **Goal:** Scale profitable paid (Meta) and organic (SEO/social) traffic above break-even ROAS.
- **Why second:** Only scale traffic once the store converts and unit economics work.
- **Key work:** Meta funnel + creative system ([`backlog/sprint-02-meta.md`](../backlog/sprint-02-meta.md)); SEO foundations.

### Phase 3 — Retention (LTV)
- **Goal:** Email/SMS lifecycle and returning-customer programmes to raise repeat rate and LTV.
- **Why third:** Cheaper to keep customers than acquire; lifts profit per customer.
- **Key work:** Core flows + campaign calendar ([`backlog/sprint-03-email.md`](../backlog/sprint-03-email.md)).

### Phase 4 — Scale (→ £10,000+/month net)
- **Goal:** Compound proven levers; systematise operations; expand range/markets where evidence supports it.
- **Why last:** Scale only what is proven profitable.

> Phases overlap in practice (e.g. SEO/content start early because they compound slowly). Sequence reflects priority, not strict gates.

## Future Vision

A clear line of sight from any sprint to the profit target. Each phase has measurable exit criteria; we advance only when the previous phase is proven. The roadmap is a living artefact that turns ambition into an ordered, evidence-gated plan.
