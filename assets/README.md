# Assets

Canonical brand and research artefacts for Edge Scarves. Treat this as the source of truth for visual identity and competitive intelligence — referenced by [`docs/02-brand-strategy.md`](../docs/02-brand-strategy.md) and the marketing/content prompts.

## Structure

| Folder | Purpose |
|---|---|
| [`brand/`](brand) | Brand guidelines, colour palette, typography, tone-of-voice, master brand files. |
| [`logos/`](logos) | Logo files in all formats and variants (primary, mono, favicon, social). |
| [`wireframes/`](wireframes) | Page/section wireframes and layout concepts (planning only — not live changes). |
| [`competitor-research/`](competitor-research) | Competitor teardowns, screenshots and positioning notes. |

## Conventions

- **Naming:** `edge-scarves_<type>_<variant>_<version>.<ext>` (e.g. `edge-scarves_logo_primary_v1.svg`).
- **Formats:** prefer vector (SVG/PDF) for logos; high-res PNG/JPG for raster; keep editable source where possible.
- **Versioning:** never overwrite — increment the version suffix and note changes in [`docs/02-brand-strategy.md`](../docs/02-brand-strategy.md).
- **Large binaries:** if files get heavy, consider Git LFS (decision: TODO).
